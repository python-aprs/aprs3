# APRS packet corpus, one TNC2 monitor-format line per packet.
#
# Each packet line is "<expected InformationField class> <TNC2 frame>". A packet must
# decode to that class and re-encode to exactly the same text (and survive a
# trip through AX.25 binary). Lines starting with "#" are comments.
#
# Sources: "APRS101 pNN" lines are examples from the APRS 1.0.1 spec on that page,
# addressed from N0CALL. The other lines are built from the formats common
# software and radios send (Dire Wolf, APRSdroid, Kenwood/Yaesu Mic-E, Xastir,
# aprx, weather stations), using test callsigns. Do not copy fixtures from
# GPL-licensed projects into this file.
#
# Non-ASCII bytes are written as \xNN escapes (the frame is decoded as latin1, like
# APRS-IS text), so "\xc3\xa9" is UTF-8 for e-acute.
#
# Known decode/encode bugs are listed in KNOWN_BUGS in test_corpus.py.
